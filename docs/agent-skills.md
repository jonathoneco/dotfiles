# Global agent skills — vendoring manifest

Canonical store: `home/.agents/skills/`. This manifest tracks what is vendored
and from where; `skills-lock.json` byte-pins every vendored SKILL.md (sha256),
is regenerated by `scripts/refresh-agent-skills.sh --apply`, and is enforced by
`validate.sh`. Refresh only through that script — staged and reviewed, with the
lock rewritten in the same apply that rewrites bodies.
